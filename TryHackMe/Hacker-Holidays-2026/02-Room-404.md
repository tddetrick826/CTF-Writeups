## 1. Challenge Overview
Day 2 focuses on web-based recon and directory fuzzing. The objective is to identify hidden routing, discover unlinked endpoints or administrative files on the target web server, and exploit misconfigurations to retrieve the flag.

---

## 2. Step-by-Step Walkthrough

## Step 1: Service Enumeration
An initial Nmap service scan was executed against the target IP to discover running services and open ports:

```bash
nmap -sC -sV <TARGET_IP>
```

Scan Findings:
Port 22/tcp: Open SSH
Port 8080/tcp: Active HTTP server hosting _Byte Lotus -- Stay Noticed_
Exposed .git Directory: Nmap detected an exposed Git repository at http://<TARGET_IP>:8080/.git/ with the initial commit message "initial Byte Lotus guest platform".

## Step 2: Extracting the Exposed Git Repository
Because the web server left its .git folder publicly accessible, wget was used to recursively download the version control repository onto the local machine:

```bash
mkdir byte-lotus-repo && cd byte-lotus-repo
wget -r -np -nH --cut-dirs=1 [http://<TARGET_IP>:8080/.git/]
```

## Step 3: Commit History Analysis & Flag Extraction
With the local .git directory rebuilt, git log -p was executed to review the entire commit history and inspect patch diffs for sensitive data:

```bash
git log -p
```
